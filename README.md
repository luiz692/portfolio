# Portfólio

Meu portfólio / currículo online. Site estático: HTML, CSS e JS puro, sem build.

## Como editar

Tudo está em `index.html`. Procure pelos comentários `✏️` — eles marcam cada coisa pra trocar (nome, textos, experiências, projetos, links, e-mail).

- **Cor de destaque:** variável `--accent` no começo do CSS.
- **Foto:** `assets/foto-recorte.png` (PNG com fundo transparente).
- **Currículo em PDF:** coloque em `assets/curriculo.pdf` (botão "Baixar CV").
- **Ícones de tecnologias:** [devicon.dev](https://devicon.dev).

## Rodar localmente

Abra o `index.html` no navegador, ou:

```bash
python -m http.server 5510
```

## Publicação

Publicado com GitHub Pages (Settings → Pages → branch `main`, pasta `/`).
